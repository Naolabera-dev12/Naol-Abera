# Security Policy for NTFY

## Supported Versions

This repository follows semantic versioning and only actively supported versions receive security updates.

| Version | Supported |
| ------- | --------- |
| 5.1.x   | ✅        |
| 5.0.x   | ❌        |
| 4.0.x   | ✅        |
| < 4.0   | ❌        |

If you are using an unsupported version, please upgrade to a supported release as soon as possible.

---

## Reporting a Vulnerability

Thank you for helping keep NTFY secure. Please do **not** create a public GitHub issue for security vulnerabilities. Instead report them privately using one of the methods below.

### Preferred contact (email)
- **security@ntfycompany.com** (preferred)
- Alternate: **ntfycompany@gmail.com**

If you choose to email, include the subject line:naolaberana@gmail.com
